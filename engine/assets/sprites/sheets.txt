# Maven Map sprite library: ChatGPT sheets (method copied from stickman-studio)
# Tiers: (1) real photos -> engine/scripts/fetch_photo.py (Wikimedia Commons, PD/free licence)
#        (2) Fluent 3D emoji already local -> engine/assets/emoji/<name>.png (MIT)
#        (3) ChatGPT sheets below -> slice with: py -3 engine/scripts/slice_sheet.py <sheet.png> engine/assets/sprites/<set> --n 8
# Flags inside borders use flag-icons SVG (MIT) -> engine/assets/flags/<iso2>.svg (accurate, not generated)
# Every object is drawn in a top-down 3/4 aerial view so it sits naturally on the satellite map.
