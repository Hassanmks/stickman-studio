# ستوديو المحتوى — تطبيق أندرويد

تطبيق يتحكم في إنتاج الفيديو كاملًا من الهاتف. العمل الثقيل كله على خوادم GitHub، والذكاء الاصطناعي تلقائي حسب المهمة: Claude عبر Coarena، ثم Gemini، ثم OpenRouter احتياطًا. الحاسوب لا يلزم.

## كيف يعمل
| الخطوة في التطبيق | ما يحدث على GitHub |
|---|---|
| «اقترح 10 مواضيع» | `brain.yml` (step=topics): الوكيل `cloud/agent.py` يقرأ `CLAUDE.md` و`TOPICS.md` و`LOG.md`، يبحث في الويب، ويكتب `cloud/state/topics.json` |
| اختيار موضوع | `brain.yml` (step=script): السيناريو، نص الصوت، أمر الصور، المصادر، الصور الحقيقية، و`cloud/state/current.json` |
| «تم — أنتج الفيديو» | يرفع التطبيق الصوت والصور إلى `inbox/<slug>/` ثم `produce.yml`: تجهيز، تصيير، البوابات الخمس، السيو. الفيديو يُرفق بالتشغيل 30 يومًا |
| «نشرته — نظّف» | `cleanup.yml`: يحذف الملفات الثقيلة حسب قاعدة التنظيف في `CLAUDE.md` |

## الاستعمال اليومي (بالخطوات)
1. افتح التطبيق ← «اقترح 10 مواضيع». يصلك إشعار حين تجهز.
2. اختر موضوعًا ← اختر الصوت ← «اكتب السيناريو». إشعار حين يجهز.
3. انسخ **نص الصوت** ← «افتح AI Studio» ← الصق ← Run ← نزّل ← **مشاركة** ← «ستوديو المحتوى».
4. انسخ **أمر الصور** ← «افتح ChatGPT» ← الصق ← نزّل الصورة ← **مشاركة** ← «ستوديو المحتوى».
5. «تم — أنتج الفيديو». إشعار حين يجهز (15–25 دقيقة).
6. شاهد الفيديو، انسخ الوصف والتعليق المثبّت، انشر، ثم «نشرته — نظّف».

## الإعدادات
- مفتاح OpenRouter: تحقق وحفظ (يُعرض الرصيد، ويُحفظ مشفّرًا على الهاتف وفي أسرار GitHub).
- رمز GitHub: صلاحيتا `repo` و`workflow`.
- النموذج وحد الإنفاق لكل خطوة. عند نفاد الرصيد يتحول الوكيل وحده إلى النماذج المجانية.
- الصوت الافتراضي، الحفظ التلقائي في المعرض، الإشعارات، المظهر، الاهتزاز، تقليل الحركة.

## البناء (للمطوّر)
```
cd android
gradlew assembleRelease
```
مفتاح التوقيع في `android/keystore/` (خارج git). احتفظ به: بدونه لا يمكن تحديث التطبيق فوق النسخة المثبتة.
